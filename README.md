<h1 align="center">Iniciando com meu primeiro Framework em CSS: Bootstrap</h1>

## Descrição do Projeto

<p align="justify">
Este projeto foi criado para demonstrar como o Bootstrap pode ser usado para desenvolver um site responsivo e visualmente atraente para uma sorveteria. Utilizando o framework Bootstrap, foi possível criar um layout profissional com elementos como cabeçalhos, carrosséis, cards, menus e modais.

:heavy_check_mark: **Assuntos abordados:**

- [x] Criação de um site de sorveteria utilizando o framework Bootstrap.
- [x] Desenvolvimento de cabeçalho, carousel, cards, menus e rodapé responsivos.
- [x] Implementação de efeitos de mapa com modal (pop-up).
- [x] Aplicação de conceitos como responsividade, agilidade e personalização com o Bootstrap.

### Vantagens do Bootstrap:
- **Responsividade**: Adapta-se automaticamente a diferentes tamanhos de tela, tornando o site acessível em dispositivos móveis e tablets.
- **Consistência**: Garante uma aparência uniforme em todos os elementos do site, independentemente de quem os desenvolveu.
- **Agilidade**: Fornece componentes predefinidos que podem ser facilmente integrados ao projeto, economizando tempo.
- **Documentação e Suporte**: Framework bem documentado e com uma grande comunidade, facilitando a resolução de dúvidas.
- **Personalização**: Flexível e altamente personalizável para criar um design único.

### Como Rodar o Projeto Localmente

1. Faça o clone deste repositório:
   ```bash
   git clone https://github.com/SuellenDiass/bootstrap-sorveteria.git
   ```

2. Navegue até o diretório do projeto:
   ```bash
   cd bootstrap-sorveteria
   ```

3. Abra o arquivo `index.html` no seu navegador.

## Funcionalidades

- **Carousel**: Um slider de imagens com os produtos da sorveteria.
- **Cards**: Cards para exibir os sabores disponíveis.
- **Modal**: Pop-up para mostrar um mapa da localização da sorveteria.
- **Responsividade**: O layout se adapta perfeitamente a diferentes dispositivos, garantindo uma boa experiência tanto em desktops quanto em dispositivos móveis.
